# Настройка окружения


## Установка sudo и выдача прав пользователю

**Входим по root`ом**

```bash
su -
```

`su без дефиса` просто переключает текущего пользователя на другого (по дефолту на root), но сохраняет переменные окружения, рабочую директорию, и настройки исходного пользователя.

`su -` переключает текущего пользователя на другого (по дефолту на root), изменяя переменные окружения, рабочую директорию, и настройки на нового пользователя.

**Установка sudo**

```bash
apt install sudo
```

**Добавляем пользователя в группу sudo**

```bash
usermod -aG sudo username
```
перезаходим пользователем в систему


## Отключить звуковой БИП! динамика

**Удалить модуль на текущий сеанс**

```bash
sudo modprobe -r pcspkr
```
```bash
sudo rmmod pcspkr
```

**Включить модуль если надо**

```bash
sudo modprobe pcspkr
```

**Запретить загрузку модуля**

добавить запись 
`blacklist pcspkr`
в файл
`/etc/modprobe.d/blacklist.conf`

*одной командой добавить в (или создать) файл*

```bash
echo "blacklist pcspkr" | sudo tee -a /etc/modprobe.d/blacklist.conf
```
